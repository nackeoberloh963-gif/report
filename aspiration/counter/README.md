# Счётчик посещений

1. Создайте пустую Google-таблицу (например, «Счётчик посещений»).
2. В ней: Расширения → Apps Script. Вставьте содержимое `Code.gs`, сохраните.
3. Настройки проекта (шестерёнка) → Свойства скрипта → добавить свойство `ADMIN_PASSWORD` с паролем администратора.
4. Развернуть → Новое развёртывание → тип «Веб-приложение»: запуск от имени «Меня», доступ «Все». Разрешите доступ.
5. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec` и вставьте его в `../config.js` в поле `COUNTER_URL`.

Пароль администратора хранится только в свойствах скрипта и в репозиторий не попадает.
